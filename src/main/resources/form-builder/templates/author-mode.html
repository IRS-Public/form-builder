Author Mode

Edit constants, fact descriptions, and on-screen text through structured forms — no XML required. Changes are validated live and saved to the source files; commit them from the command line. After saving, refresh Product Experience or Browse All to preview.

Connecting to the authoring server…

Edit a constant value

Update a tax-year threshold, rate, or limit. Values are validated against the declared type (Dollar / Rational).

Edit a fact description

Reword the human-readable description of any fact. This does not change any calculation.

Edit a fact's default & limits

Set a writable fact's default value (placeholder) and its minimum/maximum allowed values. Only writable facts with a simple scalar type are listed. Clearing a field removes it.

Edit on-screen text & structure

Pick a screen, then a question or alert on it. For a question you can edit its text, hint, input type, bound writable fact, and when it shows; for an alert its heading, type, knockout, and condition. Each field is validated and saved independently.

Edit a calculation

Edit the computation behind a derived fact — the operators, conditions, and the other facts it reads. Build the tree with the node picker; add or remove branches and Switch cases. Every change is validated against the fact-graph before it can be saved.

Create a new fact

Add a brand-new fact: a writable answer, a fixed constant, or a derived calculation. It's validated against the schema and the fact-graph (duplicate paths and bad dependencies are rejected) before it's written.

Create a new screen

Add a new page to a flow module, optionally with a first question. Add more questions and alerts afterward with the on-screen text & structure editor above.

Delete a fact

Remove a fact. First we show everything that references it — other facts and on-screen questions/alerts. Deletion is blocked while anything still depends on it; remove those references first.

Check for authoring issues

Run a soft lint over the current flow and facts — questions bound to computed facts, gates or knockouts no question can ever satisfy. These are warnings, not errors; they never block a save.
